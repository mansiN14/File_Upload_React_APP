# 📁 Smart File Upload App

A modern file upload app with React (frontend) and Flask (backend). Supports drag & drop, dark mode, validations, and category tagging. Designed for HR tech task submissions.

## ✨ Features

- 🌗 Dark/Light theme toggle
- 📂 Drag & Drop file upload
- ✅ Category selection (HR, IT, Sales, etc.)
- 📏 File type & size validation
- 🔁 Real-time upload feedback (loading spinner, success check)
- 🕒 Upload timestamp display

## 🛠 Tech Stack

- **Frontend:** React, TailwindCSS, Lucide Icons
- **Backend:** Flask (Python), CORS, Werkzeug
- **Hosting:** Netlify (frontend) + Render or Railway (backend)
